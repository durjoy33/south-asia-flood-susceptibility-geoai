# Notebook

`south_asia_flood_pixel_grouped_spatial_validation.ipynb` is the v3.2.2 workflow with saved execution outputs removed and input/output paths made configurable (see the top-level README). It produces the harmonized modelling table, grouped random and buffered spatial validation results, calibration, buffer sensitivity, the final susceptibility surface, the Gi* clusters and the validation audits. Run `python scripts/validate_notebook.py` before committing changes.
